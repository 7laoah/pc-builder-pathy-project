# PC Builder Website

This project was created as part of the **Pathy AI Development Program** certification.

The goal of the project was to apply the skills learned during the program by planning and building a complete website project from scratch with the assistance of AI tools.

## About the Project

This is a PC Builder / PC Store demonstration website created for educational purposes.

> **Disclaimer:** This is not a real commercial website. Products, prices, checkout features, and other store-related content are for demonstration purposes only.

## Technologies Used

- HTML
- CSS
- JavaScript

## Purpose

The project demonstrates skills in:

- Planning a website project
- Building a complete website from an initial idea
- Using AI tools during the development process
- Creating multiple connected web pages
- Designing a user-friendly interface
